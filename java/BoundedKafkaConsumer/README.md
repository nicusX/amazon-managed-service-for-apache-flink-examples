# Bounded Kafka Consumer

This example shows how to set up a Kafka source connector as bounded source.

The application reads from a Kafka topic JSON stock prices, which can be generated by the [FlinkDataGenerator](../FlinkDataGenerator), and send them to a Kinesis stream.

The Kafka source is configured to read from the last committed offsets or the earliest, stopping at the latest message in the topic when the job starts
